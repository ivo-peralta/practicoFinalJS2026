# Juego del dinosaurio

Un juego sencillo hecho con HTML, CSS y JavaScript usando el elemento `canvas`.

## Cómo jugar

Abre `index.html` en un navegador y pulsa la barra espaciadora para saltar los cactus. Al terminar la partida, selecciona **Reiniciar juego** para volver a empezar. El puntaje y el récord se muestran en el juego.
